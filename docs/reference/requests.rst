Request model reference
=======================

Request models are exported from :mod:`cfb_data` and from their domain model
packages. Class documentation describes Python field names, types, meaning,
and cross-field validation. The exact method signatures and defaults appear in
:doc:`namespaces`. Unknown fields are forbidden.
