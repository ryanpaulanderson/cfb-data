# Historical design documents

The files in this directory preserve analysis, implementation plans, and
completion summaries written during the repository's initial development in
2025.

They are retained as design history: they explain the assumptions, intended
validation rules, and architectural targets that shaped the current code.
They are **not** the current roadmap, API contract, or source of truth for
implementation status. Some statements marked complete may only describe the
internal test state at the time and should not be read as evidence that the
package was usable by an installed consumer.

For the current assessment and tracked next work, see
[`docs/project-status.md`](../project-status.md) and the repository's GitHub
issues.
